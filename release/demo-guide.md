# 演示说明(上架材料随附 / 供审核与宣传复用)

## 产品一句话

KinetMagicDisk 是一款纯本地、零联网的 macOS 磁盘空间可视化工具:
扫描任意文件夹,用交互式旭日图看清空间去哪了,一键把大文件夹移入废纸篓。

## 核心演示流程(60 秒脚本)

| 步骤 | 操作 | 看点 |
|---|---|---|
| 1 | 启动,点「扫描个人目录」/ Scan Home | 并发引擎,百万级文件实时进度 |
| 2 | 扫描完成,旭日图呈现 Home 全景 | 颜色稳定:每个目录固定色相 |
| 3 | 点击最大弧形区块(如 Library)下钻 | 即时下钻,面包屑回退 |
| 4 | hover 列表行,点行尾垃圾桶图标 | 系统废纸篓,可恢复;图表即时回滚大小 |
| 5 | (可选)Scan Folder… 重选目录 | 沙盒授权流程,书签记住授权 |

## 数据亮点(真实实测,MacBook Air)

- Home 全盘 1.6 TB / 330 万个项目,55 秒扫完
- TCC 保护的系统目录(Music、Daemon Containers 等)自动 5 秒超时跳过,不卡死
- 慢目录学习跳过:同前缀超时一次,后续同类目录直接短路

## 隐私叙事(对外统一口径)

- 无网络 entitlement,物理上无法上传任何数据
- 无遥测、无追踪、无账号
- `PrivacyInfo.xcprivacy`:无 tracking、无 collected data;UserDefaults 按 CA92.1 声明
- 删除走系统废纸篓(trashItem),用户随时可恢复
