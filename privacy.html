KinetMagicDisk 隐私政策

最后更新:2026-09-11 · 适用于 macOS 应用「KinetMagicDisk」

一句话版本

我们不收集你的任何数据。没有账号、没有广告、没有统计分析、没有第三方 SDK。应用不会把你的文件发送到任何服务器——事实上它根本没有网络能力。

应用能做什么

  • 扫描你选择的文件夹:枚举目录结构并按体积聚合,在屏幕上画成旭日图,列出大文件。
  • 把文件移入废纸篓:通过系统标准 API FileManager.trashItem,文件进废纸篓可恢复,绝不永久删除。
  • 记住你的选择:使用 app-scoped 安全作用域书签,以便下次「Scan Home」无需再次授权。书签只对本应用有效,无法被其它进程读取。

数据存在哪里

全部在你自己的 Mac 上。扫描结果只是渲染到窗口的画面,不写盘、不入数据库、不上传云端。书签以二进制形式存储于 macOS 标准 UserDefaults 路径下(~/Library/Preferences/com.kitnet.magicdisk.plist),仅本应用可读。

应用绝不触碰的数据

  • 位置、健康记录、通讯录、照片、麦克风、摄像头、屏幕录制
  • 浏览器历史、键盘记录、剪贴板
  • 广告标识符;不跨应用/跨网站追踪
  • 本应用不包含任何第三方分析、广告、崩溃收集、远程配置 SDK

权限说明

  • 用户选择的文件读写(User-selected read-write):沙盒标准权限。你点「Scan Folder…」选目录后,系统只授权给你那个目录(及其子目录),其它地方仍然不可读。
  • 无网络 entitlement:Info.plist 与 entitlements 中均不含 com.apple.security.network.client,应用代码层、网络层双层禁网。
  • 无自动化/辅助功能权限:不申请 Accessibility / Automation 权限,无法操控其它应用。

数据删除

应用无服务器侧数据,无需申请服务器删除。卸载应用(rm -rf /Applications/KinetMagicDisk.app 或拖入废纸篓)即彻底清除所有相关数据(包括书签)。

儿童

本应用不含面向儿童的内容,也没有公开的用户生成内容。年龄分级 4+。

联系方式

对本政策有任何问题,请联系:phinn@outlook.com

KinetMagicDisk Privacy Policy

Last updated: 2026-09-11 · Applies to the macOS app "KinetMagicDisk"

The short version

We don't collect any of your data. No accounts, no ads, no analytics, no third-party SDKs. The app never sends your files to any server — in fact, it has no network capability at all.

What the app does

  • Scans the folder you pick: enumerates the directory tree and aggregates by size, rendering a sunburst chart and a list on screen.
  • Moves files to the Trash: via the standard FileManager.trashItem API. Files go to the Trash where they can be restored; nothing is permanently deleted.
  • Remembers your choice: uses an app-scoped security-scoped bookmark so "Scan Home" doesn't need re-authorization on the next launch. The bookmark is only readable by this app.

Where your data lives

Entirely on your own Mac. Scan results are just pixels drawn on screen — not written to disk, not stored in a database, not synced to a cloud. The bookmark is stored as a binary blob in the standard macOS UserDefaults location (~/Library/Preferences/com.kitnet.magicdisk.plist), readable only by this app.

Data we never touch

  • Location, health, contacts, photos, microphone, camera, screen recording
  • Browser history, keystrokes, clipboard
  • Advertising identifiers; no cross-app or cross-site tracking
  • The app contains no third-party analytics, ad, crash-collection, or remote-config SDK

Permissions

  • User-selected file read-write: the standard sandbox permission. When you click "Scan Folder…" and pick a directory, the system grants you access to that directory only (and its subdirectories) — nothing else is readable.
  • No network entitlement: neither Info.plist nor entitlements include com.apple.security.network.client; the app is network-disabled at both the code and entitlement layers.
  • No automation / accessibility entitlements: the app does not request Accessibility or Automation rights and cannot drive other applications.

Data deletion

The app stores nothing on a server, so there's nothing to delete remotely. Uninstalling the app (drag to Trash or rm -rf /Applications/KinetMagicDisk.app) permanently removes all app-related data, including the bookmark.

Children

The app contains no content directed at children and no public user-generated content. Age rating 4+.

Contact

Questions about this policy: phinn@outlook.com

KinetMagicDisk プライバシーポリシー

最終更新:2026-09-11 · macOS アプリ「KinetMagicDisk」に適用

ひとことで

当社はユーザーのデータを一切収集しません。アカウント無し、広告無し、解析無し、サードパーティ SDK 無し。アプリがファイルをサーバーに送信することは一切ありません——そもそもネットワーク機能を一切持ちません。

アプリの機能

  • 選択したフォルダをスキャン:ディレクトリ構造を列挙してサイズで集約、画面に旭日図とリストを描画します。
  • ファイルをゴミ箱へ移動:システム標準 API FileManager.trashItem 経由。ゴミ箱から復元可能、永久削除は絶対にしません。
  • 選択を記憶:app-scoped セキュリティスコープドブックマークを使用し、次回「Scan Home」で再認証が不要になります。ブックマークはこのアプリからのみ読み取り可能。

データの保存場所

すべてあなたの Mac 内に保存されます。スキャン結果は画面に描画されるピクセルであり、ディスク書き込みもデータベース保存もクラウド同期も一切行いません。ブックマークは macOS 標準 UserDefaults(~/Library/Preferences/com.kitnet.magicdisk.plist)にバイナリ保存され、本アプリのみが読み取り可能です。

アプリが絶対に扱わないデータ

  • 位置情報、健康記録、連絡先、写真、マイク、カメラ、画面収録
  • 閲覧履歴、キーボード入力履歴、クリップボード
  • 広告識別子。アプリ間/サイト間のトラッキングは一切行いません
  • 本アプリにはサードパーティの解析・広告・クラッシュ収集・遠隔設定 SDK は一切含まれていません

権限について

  • ユーザー選択のファイル読み書き:サンドボックス標準権限。「Scan Folder…」でディレクトリを選択すると、システムはそのディレクトリ(とそのサブディレクトリ)のみへのアクセス権を付与します。
  • ネットワーク entitlement 無し:Info.plist にも entitlements にも com.apple.security.network.client を含まず、コード層・entitlement 層の二重でネットワークを遮断。
  • 自動化/アクセシビリティ権限無し:Accessibility や Automation 権限を申請せず、他のアプリケーションを操作することはできません。

データの削除

アプリ側にサーバーデータは存在しないため、遠隔削除の申請は不要です。アプリをアンインストール(ゴミ箱へドラッグ、または rm -rf /Applications/KinetMagicDisk.app)することで、ブックマークを含むすべての関連データが完全に削除されます。

お子様について

本アプリにはお子様向けコンテンツや公開されたユーザー生成コンテンツは含まれません。年齢レーティングは 4+。
