KinetMagicDisk

ディスクの容量を、ひと目で把握。KinetMagicDisk は任意のフォルダをスキャンし(ホーム全体も OK)、サンバースト図に変換します。容量を圧迫している犯人が数秒で見つかり、ワンクリックでお片付け。

高速スキャン
• モダンな Mac 向けに設計された並列スキャンエンジン。数百万件の項目もスムーズに処理
• スキャン中はライブで進行状況を表示。完了と同時にすべて操作可能
• 円弧をクリックして階層を掘り下げ、パンくずリストでひとつ上へ戻る

サンバースト可視化
• すべてのファイルとフォルダを、実際の使用量に比例したリングとして描画
• フォルダごとに安定した色を保持し、再スキャンしても見分けやすい
• 円弧にホバーすると、確定前に名前とサイズをプレビュー

ワンクリックでお片付け
• 不要なフォルダを見つけたら、リストから直接ゴミ箱へ移動
• ツリーは即座に更新。削除後の再スキャンは不要
• ファイルは必ずゴミ箱経由。取り消し可能な安全なお片付け

プライバシー重視の設計
• ネットワーク通信なし。アナリティクスもトラッキングも一切なし
• スキャンは macOS サンドボックス内で完全ローカルに実行
• ユーザーが明示的に許可したフォルダのみアクセス

macOS のために、SwiftUI でネイティブに構築。Apple Silicon と Intel の両方で快適に動作。

大きなダウンロードの前にギガバイトを取り戻すときも、ディスクの行き先が気になるときも、KinetMagicDisk ならひと目でわかります。
