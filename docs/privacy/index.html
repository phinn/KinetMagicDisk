KinetMagicDisk Privacy Policy

Last updated: September 9, 2026 · Applies to KinetMagicDisk for macOS

Overview

KinetMagicDisk is a disk space analyzer. We do not collect, transmit, sell, or share any of your data. The app contains no analytics, no tracking, no advertising, and no network access at all.

Data the app accesses

To visualize disk usage, KinetMagicDisk reads file metadata (names, sizes, timestamps) of folders you explicitly choose:

  • You pick a folder with the system open panel, or grant access to your Home folder.
  • All scanning happens locally on your Mac, inside the macOS App Sandbox.
  • Selected-folder permissions are remembered using a security-scoped bookmark stored in the app's own sandbox container.

Data storage

All data stays on your device:

  • Scan results live only in memory while the app runs.
  • The saved folder bookmark and app preferences stay inside the app's sandboxed container.
  • Deleting files moves them to the macOS Trash via the system API — nothing is erased permanently by the app.

Network access

None. KinetMagicDisk performs no network requests of any kind.

Children's privacy

The app does not knowingly collect any personal information from anyone, including children under 13.

Changes

If this policy changes, the updated version will be posted at this URL with a new "Last updated" date.

Contact

Questions about privacy: phinn@outlook.com

KinetMagicDisk プライバシーポリシー

最終更新日: 2026年9月9日 · 本ポリシーは macOS 版 KinetMagicDisk に適用されます

概要

KinetMagicDisk はディスク容量分析アプリです。お客様のデータを収集・送信・販売・共有することは一切ありません。本アプリにはアナリティクス、トラッキング、広告は含まれておらず、ネットワークアクセスも一切行いません。

アプリがアクセスするデータ

ディスク使用状況を可視化するため、KinetMagicDisk はユーザーが明示的に選択したフォルダのファイルメタデータ(名前・サイズ・タイムスタンプ)を読み取ります。

  • システムのファイル選択パネルでフォルダを選択するか、ホームフォルダへのアクセスを許可してください。
  • すべてのスキャンは macOS の App Sandbox 内で、お使いの Mac 上でローカルに実行されます。
  • 選択したフォルダへのアクセス権は、セキュリティスコープドブックマークとしてアプリ自身のサンドボックスコンテナ内に保存されます。

データの保存

すべてのデータはお使いのデバイス内に留まります。

  • スキャン結果はアプリの実行中のみメモリ上に存在します。
  • 保存されたフォルダのブックマークとアプリ設定は、アプリのサンドボックスコンテナ内に保存されます。
  • ファイルの削除はシステム API を経由して macOS のゴミ箱へ移動するのみで、アプリが完全に消去することはありません。

ネットワークアクセス

ありません。KinetMagicDisk はいかなるネットワーク要求も行いません。

児童のプライバシー

本アプリは、13歳未満の児童を含むいかなる方からも、個人情報を意図的に収集することはありません。

変更

KinetMagicDisk 隐私政策

最后更新:2026 年 9 月 9 日 · 适用于 macOS 版 KinetMagicDisk

概述

KinetMagicDisk 是一款磁盘空间分析工具。我们不会收集、传输、出售或共享您的任何数据。应用不含任何统计、追踪或广告,也完全不进行网络访问。

应用访问的数据

为可视化磁盘使用情况,KinetMagicDisk 会读取您明确选择的文件夹的文件元数据(名称、大小、时间戳):

  • 您通过系统文件选择面板选取文件夹,或授权访问个人目录(Home)。
  • 所有扫描均在您 Mac 本地的 macOS App Sandbox 内完成。
  • 已选文件夹的访问权限以安全作用域书签形式,保存在应用自己的沙盒容器内。

数据存储

所有数据都只保留在您的设备上:

  • 扫描结果仅在应用运行期间存在于内存中。
  • 文件夹书签与应用偏好设置均保存在应用的沙盒容器内。
  • 删除文件通过系统 API 移入 macOS 废纸篓——应用不会永久抹除任何内容。

网络访问

无。KinetMagicDisk 不发起任何形式的网络请求。

儿童隐私

本应用不会有意收集任何人(包括 13 岁以下儿童)的个人信息。

政策变更
